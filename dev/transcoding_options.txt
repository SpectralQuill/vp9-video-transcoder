✅ Recommended Details Panel Structure
1. Original Video (Read-only, auto-detected)

    These should help the user understand why the transcoding will take time and what quality to expect:

    Basic Info

        Thumbnail / Preview Frame

        Resolution (e.g., 1920×1080)

        FPS (e.g., 29.97)

        Duration (e.g., 01:24:51)

        File Size

        Codec (VP9? H.264? etc.)

        Bitrate (overall)

        Video Bitrate

        Audio Stream

            Codec (AAC / Opus / MP3)

            Channels (Stereo / Mono)

            Sample rate

            Audio bitrate

        (These are all extractable using ffprobe.)

2. Output Settings (Editable, simple)

    Casual users need simplicity—but you want them to still have control. Here’s a minimal but powerful set:

    Destination

        Folder (editable)

        Filename (editable)

        Output format → Always .mp4 (webm inside mp4 container)
        (Disabled dropdown for clarity)

3. Transcoding Profile (Editable, friendly)

    Below is the best balance between simplicity and real ffmpeg control.

    Resolution

        Same as original

        720p

        480p

        360p

        Custom… (user types width/height)

        Internally maps to -vf scale=-1:720 etc.

    Quality (CRF)

        Label this something users understand:

    Quality / File Size slider

        Descriptions:

            High Quality (CRF 22)

            Balanced (CRF 28)

            Small File (CRF 32)

            Very Small File (CRF 35)

        Users don’t need to know the number, but you can show it lightly.

        Maps to:
        -crf N

    Encoding Speed

        Simple names that map to -cpu-used:

        UI	ffmpeg
        Best Quality (Slow)	-cpu-used 0
        Balanced	-cpu-used 1
        Fast	-cpu-used 3
        Very Fast (Low Quality)	-cpu-used 5

    Audio Options

        Codec:

            Opus (recommended)

            AAC

        Bitrate: dropdown

            64k

            96k

            128k

            192k

4. Advanced (Collapsible)

    For enthusiasts who want more control but still simple:

    Tile Columns (-tile-columns)

    Threads (-threads)

    Row MT (toggle)

    VBR vs CBR (just selects -b:v 0 or sets a bitrate)

    Keep original audio (copy audio stream)

5. Progress and Status

    During encoding:

        Progress bar

        FPS (live)

        ETA

        Current pass (1 or 2)

        Output file size (live if possible)

    Resolution
